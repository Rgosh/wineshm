# The block that changes while the game is running. Naming it is what lets the
# bridge notice the game has gone and zero everything, so the last frame of a
# session that ended does not read as a live one.
#
# It has to be a block that moves constantly. The static block looks like the
# obvious choice — the car and the track are in it — and it is the wrong one:
# it is written once a session and never again, so it would look dead
# immediately and blank a session that is still running.
